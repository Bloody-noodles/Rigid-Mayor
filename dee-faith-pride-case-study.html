01 / The challenge

Make the service offer easier to understand.

The business needed an online destination where visitors could browse its digital services, understand what was available, and contact the business without having to work out the next step themselves.

02 / The approach

Build around discovery and enquiry.

Service discovery

Organised services into a browsable catalogue so visitors can explore the offer before contacting the business.

Direct contact

Added service-specific WhatsApp enquiry paths to help interested visitors start a conversation.

Booking-related pages

Included booking and appointment-related pages as part of the customer-facing experience.

Responsive experience

Checked the deployed website on mobile layouts as well as the main customer-facing flows.

03 / Implementation

Tools and working method

The site was built with an AI-assisted workflow, with implementation work reviewed and key customer-facing features tested rather than assuming generated code was correct.

  • Astro for the website framework
  • TypeScript for typed application code
  • Tailwind CSS for styling
  • Vercel for public deployment

04 / Outcome and scope

A live website with a clearer route to contact.

The project is publicly deployed, with the service catalogue, WhatsApp enquiry paths, booking-related pages, and mobile experience checked.

Scope note: Database-backed administration and order workflows require further configuration. They are not represented here as verified production features. No measured change in sales, enquiries, or revenue is being claimed.

05 / What this demonstrates

Practical delivery, with honest boundaries.

This project demonstrates the ability to shape a real business need into a deployed web experience, prioritise customer-facing actions, use AI tools as part of development, and distinguish tested functionality from work that still needs configuration.
