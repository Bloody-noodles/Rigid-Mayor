## Featured Project — VisionSense-AI

**VisionSense-AI** is a real-time human detection and multi-object tracking system built with **YOLO11n** and **ByteTrack**.

It can process live or demo video, track subjects, analyze movement, record events, and expose session analytics through a **FastAPI** backend and **Next.js** dashboard.

- **Live demo:** https://vision-sense-ai-wine.vercel.app/
- **Source:** https://github.com/Bloody-noodles/VisionSense-AI
